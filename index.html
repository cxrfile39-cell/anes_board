📝 搜尋邏輯說明 Search Methodology

① 資料來源與時間範圍

  • 資料來源：美國國家醫學圖書館 PubMed（NCBI E-utilities API）。
  • 每週一台北時間 07:30 左右自動執行（11:20 另有備援；排程若延遲或失敗，下一次執行會自動補齊），抓取前 7 天（上週一至週日）新收錄進 PubMed 的文章。
  • 依 PubMed「收錄日 Entrez date」計算，因此包含線上搶先刊登（Epub ahead of print）的文章；收錄日與期刊出版日可能不同。
  • 搜尋區間：「7 天」顯示每週自動整理的資料；選「30 天／1 年／2 年」時，網頁會用同一套檢索式即時向 PubMed 搜尋，各區塊數字為 PubMed 實際總篇數，每次載入 20 篇，並可輸入關鍵字縮小範圍。

② 共同篩選條件

  • 收錄類型：Journal Article、Review、Systematic Review、Meta-Analysis、Guideline、Practice Guideline。
  • 排除類型：Comment、Editorial、Letter、Published Erratum、Retraction、News、Case Reports。
  • 語言：英文。
  • 每個次專科每週最多收 300 篇（依出版日期取最新）；網站保留最近 26 週。

③ 文章類型分類（四區塊）

  • 依 PubMed 的 Publication Type 判定，同時符合多類時優先序為：指引 ＞ 統合分析 ＞ 綜述 ＞ 原始研究。
  • 📋 共識／指引：Guideline、Practice Guideline、Consensus Development Conference
  • 📊 統合分析：Meta-Analysis、Systematic Review
  • 📚 綜述：Review、Scoping Review
  • 🔬 原始研究：其餘期刊論文（RCT、世代研究、基礎研究等）

④ 「麻醉相關」的定義

下表中的「麻醉」指符合以下任一條件：MeSH 主題詞 Anesthesia、Anesthesiology、Anesthetics，或標題／摘要含 anesthe*、anaesthe*、perioperative。

⑥ 影響係數 Impact Factor

  • IF 9.1：官方 Clarivate JCR 影響係數，由管理者手動填入 journal_if.json。
  • IF≈ 6.2：JCR 為付費資料無法自動取得，故其餘期刊使用 OpenAlex「2 年平均被引次數」（期刊前兩年文章在當年的平均被引用次數，計算方式與 IF 相同），每月自動更新。數值與 JCR 官方 IF 相近但不完全相同，僅供參考。
  • IF 反映的是期刊整體被引用情形，不代表單篇文章的品質。

⑦ 中文重點

  • 每週更新後，由 Claude（Anthropic AI）依各篇的標題與摘要，自動撰寫一句繁體中文重點。
  • 只根據 PubMed 公開的標題與摘要撰寫，不含全文內容；可能有錯誤或遺漏，請以原文為準，不可作為臨床決策依據。
  • 即時搜尋（30 天／1 年／2 年）的結果不提供中文重點。

⑧ 使用限制

  • 分類以期刊名稱與關鍵字自動判定，可能有誤收或漏收；同一篇文章可能同時出現在多個次專科。
  • 新收錄的文章通常尚未完成 MeSH 標引，初期主要依標題與摘要比對。
  • 本站僅為文獻快訊整理，內容請以原始文獻為準，不構成臨床建議。
